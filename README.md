# Proyecto Python: VIRTUAL_PROFESSOR

Este proyecto permite cargar archivos de temario en formato PDF o DOCX a través de una interfaz web simple.

## Estructura
- main.py: Script de ejemplo "Hello, World!"
- src/app.py: Aplicación Flask para carga de archivos
- src/templates/upload.html: Vista web para subir archivos
- requirements.txt: Dependencias del proyecto

## Ejecución de la app web
Instala las dependencias:
```bash
pip install -r requirements.txt
```
Ejecuta la aplicación:
```bash
cd src
python app.py
```
Luego abre tu navegador en http://127.0.0.1:5000
